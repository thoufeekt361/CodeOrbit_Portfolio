# 🌐 3D Personal Portfolio Website

A modern and interactive **3D animated personal portfolio website** built using **HTML, CSS, and JavaScript**. The portfolio showcases my education, technical skills, internships, projects, certifications, and contact information through an attractive responsive interface.

The website combines **3D animations, glassmorphism, glowing effects, interactive cards, hover animations, and responsive layouts** to create an engaging portfolio experience without using any frontend framework.

# ⚙️ Installation

Follow these steps to run the portfolio locally.

### 1. Clone the repository

https://github.com/thoufeekt361/CodeOrbit_Portfolio

### 2. Open the project

cd CodeOrbit_Portfolio

### 3. Run the project

Since this project uses HTML, CSS, and JavaScript, you can simply open:

```text
index.html
```

in your browser.

You can also use **VS Code Live Server** for easier development.

---

# 💻 Run Using VS Code

1. Clone the repository.
2. Open the project folder in **VS Code**.
3. Install the **Live Server** extension.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
6. The portfolio will open in your browser.
